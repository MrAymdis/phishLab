导航菜单结构（11项统一）：数据概览 → 演练管理 → 素材模板 → 发送配置 → 用户和组 → 安全培训 → 数据报表 → 邮件举报 → 系统设置 → 智能助手 → API开放平台

一、 数据概览
演练核心指标展示（本月演练次数、演练人数、平均中招率、平均举报率、培训通过率），支持近7天/本月/本季度筛选切换，指标数据联动变化
已开展的演练活动方式分类统计分布（邮件钓鱼演练，短信钓鱼演练，社交媒体钓鱼次数），饼图随筛选周期联动
风险趋势图表（柱状+折线混合图：柱状=中招人数，折线=中招率%，随筛选周期联动，不单独筛选周/月/季度）
中招高危人员/部门TOP 5 排行榜 / 浏览器指纹饼图（随筛选周期联动）
进行中的演练实时状态（随筛选周期联动）：
已投递数量
已阅读数量
已点击数量
已提交数量
已举报数量
平台运营数据板块（固定数据，不随筛选变化）：
邮件钓鱼模板数
口令钓鱼模板数
二维码钓鱼模板数
水坑钓鱼模板数
钓鱼话术数
近期计划演练（固定数据，不随筛选变化）
活动名称，活动日期，目标对象/部门

二、 演练管理
1. 演练列表
查看所有历史、进行中、待开始的演练
统计卡片筛选（全部/进行中/待开始/已完成/已终止）
演练状态的启动、暂停、终止
投递进度+点击进度双进度条可视化
2. 发起演练（7步向导式）
Step 1: 基础设置 - 演练名称、描述、演练类型（邮件钓鱼/短信钓鱼/USB实物钓鱼/社交媒体钓鱼）
Step 2: 选择目标 - 按部门、标签或导入CSV选择被测人员
Step 3: 选择模板 - 选择钓鱼邮件模板、发件人伪装名称、欺骗性域名配置
Step 4: 落地页配置 - 选择钓鱼网站落地页、数据收集表单配置（如模拟登录页）
Step 5: 发送配置 - 选择已配置的发送通道方案（SMTP/EWS/SMS），显示送达率预估和DNS状态，支持发送测试，具体配置在「发送配置」模块完成
Step 6: 触发机制 - 立即发送或定时发送、分批次发送策略（防拥堵/防发现）、高级防识别设置
Step 7: 培训跳转 - 中招后处理方式（立即跳转培训/仅显示教育弹窗/不强制处理）、关联培训课程、配置确认清单
3. 演练详情监控
实时数据大屏（发送成功数、打开数、点击数、中招数、举报数）及转化率
转化漏斗分析（发送→打开→点击→输入→举报）
高危中招预警列表
用户行为时间轴（谁在什么时间打开了邮件、点击了链接），每条行为附带浏览器指纹和IP地址信息
实时预警（针对高危中招用户的即时通知）

三、 素材模板
1. 钓鱼邮件模板
内置模板库（节假日、系统升级、中奖、HR通知、财务报销等场景）
自定义模板编辑（富文本编辑器，支持插入动态追踪变量如{{.FirstName}}）
模板测试发送
2. 钓鱼落地页管理
仿冒页面库（企业邮箱登录、OA系统登录、网盘认证等）
页面克隆工具（输入URL自动抓取并生成仿冒页面）
自定义页面构建器
3. 附件与载荷管理
带宏的Word/Excel文件管理
免杀EXE/木马载荷管理（进阶功能，视平台定位而定）
二维码生成器（用于扫码钓鱼）

四、 发送配置
1. 发送通道管理（支持三种认证方式）
SMTP - 标准邮件发送协议，配置服务器地址、端口、加密方式（STARTTLS/SSL/无加密）、账号密码
Exchange (EWS) - Office365/本地Exchange，配置EWS服务URL、认证账号密码、认证模式（基本认证/OAuth 2.0），OAuth模式下配置Azure AD应用（Client ID/Secret/Tenant ID）
短信机 (SMS) - 短信网关API/4G模块，支持阿里云/腾讯云/华为云/网易云信/自定义HTTP网关/4G短信模块（串口AT指令），配置API地址、签名、API Key/Secret、短信模板ID
2. 伪装发件人配置（已合并至发送配置内）
发件人显示名称伪装
邮件类型：发件邮箱地址、回复地址（Reply-To）
短信类型：短信发送号码、短信签名
适用场景标签（财务类/HR类/系统类/节假日/中奖类/安全类）
3. 域名与DNS管理
演练专用域名配置
DNS解析记录状态检测（SPF/DKIM/DMARC）
送达评分（0-100分，颜色分级）
DNS配置修复指引

五、 用户和组
1. 组织架构管理
部门树的建立与维护
支持与企业微信、钉钉、飞书或AD域/LDAP的同步对接
2. 员工档案
员工基础信息（姓名、邮箱、手机号、部门、岗位）
员工风险画像（历史中招次数、培训完成度计算出的个人风险值）
3. 分组与标签
自定义人员分组（如高管组、研发组、新员工组）
标签管理（用于精准定向演练）

六、 安全培训
注：此模块用于"演"完后的"练"，形成闭环。
1. 培训课程库
视频、图文、PDF课件管理
互动式课程/小游戏
2. 培训计划管理
创建培训任务（指定人群、完成期限）
强制分配（针对本次演练中招的人员自动下发培训）
3. 考试与测评
题库管理（单选、多选、判断）
组卷与发布
通关分数线设置

七、 数据报表
1. 演练报表
单次演练详细报表（支持导出PDF/Excel）
漏斗图分析（发送 -> 打开 -> 点击 -> 输入数据 -> 附件运行）
2. 部门报表
各部门安全意识横向对比
部门内人员明细清单
3. 综合趋势报表
跨演练的趋势分析（评估企业整体安全意识是否在提升）
按场景分析（如员工对"财务类"钓鱼防范意识差，对"HR类"防范好）
4. 员工个人报表
个人安全档案（历史演练行为轨迹、培训记录）

八、 邮件举报
注：这是现代钓鱼演练平台的重要功能，鼓励员工积极举报。
1. 举报插件管理
员工邮箱客户端插件（Outlook插件或Web邮箱按钮）的下载与分发
举报API接口配置
2. 举报中心
员工通过插件举报的邮件汇总
真实钓鱼邮件与演练钓鱼邮件的自动分类识别
误报处理（员工将正常邮件举报为钓鱼的记录）
举报奖励机制（积分发放、排行榜）

九、 系统设置
1. 权限管理 (RBAC)
角色管理（超级管理员、演练操作员、只读审计员）
菜单权限与数据权限隔离（例如A管理员只能看自己部门的演练数据）
2. 审计日志
系统操作日志（谁在什么时间创建了演练、修改了配置）
登录日志
3. 系统集成
单点登录 (SSO) 配置
SOC/态势感知平台告警对接（SIEM集成，如Syslog推送）
Webhook消息推送（演练结果推送到企业微信/钉钉/飞书群）
4. 基础参数设置
平台Logo、名称、版权信息配置
邮件追踪像素配置
数据留存周期设置（满足合规与隐私要求）
5. 授权管理（软件产品授权）
授权状态概览（正式版/试用版/过期、授权类型、到期时间、剩余天数）
授权信息（授权Key、客户名称、授权用户数配额、邮件/短信发送量配额、演练次数配额，进度条展示用量）
功能模块控制（基于授权等级自动控制各模块启用/禁用状态，如高级AI分析、API开放平台需旗舰版授权）
在线激活/续期（激活码输入、在线验证、离线激活文件导入.lic、联系销售）

全局AI层设计

1. Copilot 侧边栏（全局）
所有页面右侧可唤起的对话抽屉，作为平台统一AI入口
上下文感知：自动携带当前页面上下文（如在演练详情页可问「这次演练哪里问题最大」）
页面锚定操作：AI回答中可内嵌可执行动作按钮（如「一键生成报告」），点击后跳转对应功能
多轮对话与会话管理：支持历史会话保存与回溯
每个页面配有专属快捷问题标签（如数据概览页为"本月中招率趋势"、演练管理页为"分析演练效果"）

2. ChatBI 自然语言问数
工作台与数据报表模块支持自然语言查询数据（如输入「上月财务部中招率趋势」直接生成图表与结论）
前端配套文本输入框与图表渲染容器（复用现有图表组件）
回显AI生成的查询逻辑（SQL等价查询），保证可解释性
支持快捷查询建议标签
查询结果支持导出

3. 流式输出与交互规范
所有AI生成内容采用SSE（Server-Sent Events）流式返回，前端打字机效果渲染
统一的生成态（loading/进度动画）、失败态（重试按钮）、空态UI模式
生成内容以Markdown渲染，支持表格、列表、代码块等富文本结构

4. 生成内容审核态（全局硬约束）
AI产出（模板文案、落地页、课程、报告摘要等）一律先进入草稿态，经人工确认后生效
前端提供统一的「AI生成 → 预览 → 修改 → 确认入库」组件流程
草稿卡片包含：标题、内容预览、草稿待审核badge、预览/确认入库/丢弃按钮
审核操作记录操作人与时间，进入审计日志
确认入库后badge变为"已确认"，显示审核人和审核时间

开发建议（避坑指南）：
1.防反查机制：演练邮件很容易被企业网关或员工识破，系统需要具备绕过基础反垃圾网关的能力（如随机化邮件内容、图片代替文字、延迟发送）。
2.用户体验：落地页一旦员工输入密码或点击，应立即给予友好的教育提示（如弹窗："这是一次演练，您刚才差点泄露了密码！"），而不是什么都不做，否则失去教育意义。
3.数据隐私与合规：收集员工"中招"数据非常敏感，系统设计必须注重权限管控，确保只有授权的安全人员可见，不可用于绩效惩罚（行业内通常强调"教育为主，惩罚为辅"），建议在系统中加入免责声明和合规提示。
4.MVP阶段建议：如果资源有限，第一期（MVP）重点做：工作台、演练管理、人员管理、邮件模板管理、基础报表。培训模块和举报插件可放到第二期。
