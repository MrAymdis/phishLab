# 离线交付说明（无外网目标机）

发布包自带两块"软件包"，目标机**不需要访问外网**即可完成部署：

## 1. Python 依赖离线 wheel —— `server/vendor/wheels/`

- 已按 `python:3.11-slim` 目标环境（cp311 / manylinux2014 x86_64 + 纯 Python 通用 wheel）预下载，覆盖 `fastapi / uvicorn[standard] / sqlalchemy / alembic / pymysql / cryptography / pydantic / redis / celery / httpx / sse-starlette / aiosmtplib / exchangelib / minio / openpyxl / sqlglot（ChatBI）/ qrcode / pillow` 等全部运行依赖。
- `deploy/server.Dockerfile` 构建时通过 `pip install --find-links=server/vendor/wheels ...` 优先命中本地 wheel；目录为空或个别包缺失时回源 PyPI（联网机器行为不变）。
- **源码升级后重新生成**（联网机器上执行）：

```bash
cd server
pip download -d vendor/wheels --python-version 311 --implementation cp \
  --platform manylinux2014_x86_64 --platform any --only-binary=:all: \
  fastapi "uvicorn[standard]" sqlalchemy alembic pymysql cryptography \
  pydantic pydantic-settings email-validator redis celery httpx sse-starlette \
  pyjwt aiosmtplib dnspython exchangelib minio openpyxl python-multipart \
  sqlglot qrcode pillow pytest
```

## 2. 基础镜像包 —— `images.tar`

编排依赖 5 个 Docker Hub 基础镜像：`mysql:8.0 / redis:7-alpine / minio/minio / nginx:alpine / python:3.11-slim`。
`server` 镜像由发布包内源码在目标机 `docker build` 产出，**不需要**打包。

- **联网机器**上执行 `bash deploy/export-images.sh` 导出 `images.tar`；
- **目标机**上执行 `bash deploy/load-images.sh images.tar` 导入；
- 之后按《部署手册.md》§4 正常 `docker compose up -d --build`。

> 若目标机可访问 Docker Hub，可跳过 2，直接按《部署手册.md》部署。
