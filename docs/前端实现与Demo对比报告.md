## 横向共性问题（跨页面）

1. **表单弹窗普遍缺失**（影响一期可用性最大）：新建/编辑邮件模板、新建落地页（表单字段配置）、上传附件、SMTP/EWS/SMS 通道表单、添加域名、新建课程、添加员工、角色属性表单等约 10+ 个 demo 核心弹窗未实现或仅有按钮。
2. **筛选/搜索控件"有壳无逻辑"**：用户和组、培训、API 应用搜索、调用日志、模板类型筛选等多处控件仅绑定 v-model，无过滤实现。
3. **统计卡片体系不完整**：演练管理/概览的核心卡已还原，但各子模块统计卡（用户和组 4、培训 10、素材模板 11、发送配置 4、审计 3、举报 5 部分）缺失较多。
4. **行级操作不全**：表格复选框/全选（批量操作前提）、编辑/复制/删除/导出、危险操作二次确认，多页缺失。
5. **ChatBI 整块缺失**：概览页与报表页 demo 均含"自然语言问数条 + SQL 回显 + 图表结论 + 导出"，实现仅报表页留了输入框。
6. **Mock 数据与 demo 数值不一致**：真实举报数 98 vs 62、奖励规则 +5/+20/+10/+3 vs +10/+50/+100/+20、送达评分阈值 90/60 vs 98/90、配额百分比、模板总数 48 vs 46 等（若以 demo 为验收基准需对齐）。
7. **选项枚举被替换**：场景标签（"安全告警"→"其他"）、模板名称与分类、伪装域名选项、语气风格文案、分批策略预设文案等，功能等价但文案不同。
8. **demo 自身不一致**（实现已按多数处理）：演练管理 demo 导航顺序（用户和组↔发送配置）与其他 10 页相反，实现采用多数顺序 ✅。
